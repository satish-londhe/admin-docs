# Reseller

CMP supports **Reseller** and **Vendor** partner account types in addition to end **Customers**. Resellers get a white-labeled portal and control customer billing; vendors onboard customers on the provider portal and are billed for aggregated customer usage.

:::warning[Known limitations — not bugs]

Several reseller capabilities are **not available yet** or are under review / QA. Treat them as documented product limits until future releases — see [Current limitations](/platform-features/reseller/reseller-billing#current-limitations-known-gaps). Do not report these as defects unless behaviour differs from this documentation.

:::

## Quick comparison

| | **Reseller** | **Vendor** |
|---|---|---|
| **Portal** | Own whitelisted URL | Provider’s URL |
| **Customer billing** | Reseller bills customers (invoices) | No customer invoices — vendor is billed |
| **Package pricing** | Can change prices / add margin on assigned plans | Cannot change provider-assigned prices |
| **Create own plans** | No — only change existing assigned plans | No |

Full matrix: [Reseller vs Vendor](/platform-features/reseller/reseller-vs-vendor).
