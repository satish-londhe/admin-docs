# Referred Signups

**Path:** **Report → Referred Signups**

Lists customers who registered using this affiliate's referral link or code.

![Screenshot: Affiliate — Referred Signups](/img/screenshots/cmp-affiliate-dashboard-referred-signups.png)

---

## Table columns

| Column | Description |
|---|---|
| **Client ID** | Customer CRN — for example `#001059` |
| **Name** | Customer display name |
| **Status** | Customer account status — for example **ACTIVE** |
| **Commission** | Total commission earned from this referred customer |
| **Created At** | When the customer registered via the referral link |

Use the search bar, refresh, and filter controls to narrow results.

:::info[Email notification]

The affiliate receives an **email** when a referred customer completes signup.

:::

Admins see the same data per affiliate under [Referred Signups (Admin)](/platform-features/affiliate/admin/affiliate-details#referred-signups).
