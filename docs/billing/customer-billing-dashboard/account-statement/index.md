# Account Statement

**Account Statement** groups formal billing records and usage for the customer account.

**Customer path:** **Billing → Account Statement**

## Sections under Account Statement

| Section | Purpose |
|---|---|
| **Invoices** | Issued invoices (and related documents) for the account |
| **Usage Details** | Service usage lines and amounts — behaviour depends on payment mode and prepaid receipt setting — see [Usage Details](/billing/customer-billing-dashboard/account-statement/usage-details) |
| **Free Credits** | Free credit grants applied to the account |
| **Service Contracts** | Contract records when used |
| **Free Trials** | Free trial services |

:::info[Usage vs invoices]

**Usage Details** shows consumption that is still open or tracked for reporting. **Invoices** shows documents already generated. Which usage appears on Usage Details changes with prepaid Model 1 vs Model 2 and with postpaid / manual — explained on the [Usage Details](/billing/customer-billing-dashboard/account-statement/usage-details) page.

:::
