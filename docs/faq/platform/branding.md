# Branding & themes

## How can a provider add external document URLs from their own website?

As admin, set the **Knowledge Base URL** in **Branding** settings.

Once saved, end users see the link:

* In the left menu  
* On the dashboard  

Clicking it opens your external documentation site.

## How can I change images for Login, Register, Forgot Password, Logout, and 2FA pages?

CMP supports multiple auth theme templates. **Image customization** is available for:

**Theme1**, **Theme2**, and **Theme3**

Other themes may not expose background image controls.

### Steps

1. Go to **Admin → Branding Settings → Theme Configuration**  
2. Select **Theme1**, **Theme2**, or **Theme3**  
3. Apply the theme, then open **edit theme**  
4. Upload or replace the images  
5. Save and clear cache if your deployment requires it
