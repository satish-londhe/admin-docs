# Settings & preferences

## How do we change the default date-time format for the application and for an account?

### Application-level

**Path:** **Admin → Global Settings** → **`default_date_time_format`**

* Applies to **newly created** accounts  
* Existing accounts keep their current format  

### Account-level

Users set format under **Profile → Preferences**.

* Account preference **overrides** the application default when set
