# FAQ & Q&A

Customer and admin questions answered by topic. Use this section for **support-style** answers; use feature guides (Billing, Orchestrators, Platform Features) for full setup procedures.

## How navigation is organised

| Area | What belongs here | Browse |
|---|---|---|
| **Platform** | CMP product behaviour that does **not** depend on CloudStack / OpenStack / etc. — billing, prepaid, branding, 2FA, accounts, coupons | [Platform Q&A](/faq/platform/) |
| **Orchestrators** | Behaviour that depends on the connected cloud (or applies the same way on **all** orchestrators) | [Orchestrator Q&A](/faq/orchestrators/) |

```text
FAQ & Q&A
├── Platform          → billing, branding, auth, accounts, packages (CMP)
└── Orchestrators
    ├── All orchestrators   → same answer for CloudStack, OpenStack, …
    ├── CloudStack
    ├── OpenStack
    └── …
```

## Tags (find related answers)

Every Q&A page uses frontmatter **tags**. Prefer these conventions:

| Tag | Use when |
|---|---|
| `faq` | All FAQ pages |
| `platform` | CMP-wide answers |
| `all-orchestrators` | Same answer for every connected orchestrator |
| `cloudstack` / `openstack` / `vmware` / `proxmox` / … | Orchestrator-specific |
| Topic tags | e.g. `billing`, `prepaid`, `vm`, `networking`, `auth`, `branding`, `snapshots`, `ip-address` |

In the docs site, open a tag (for example from a page footer) to list other pages with that label — useful when a question is tagged both `billing` and `cloudstack`.
