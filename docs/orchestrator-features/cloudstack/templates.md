# Templates

Customer **My Templates** and template usage in CMP for CloudStack — create templates from VMs, manage account templates, and use them when provisioning instances.

Admin-side template registration and CMP template configuration are covered under Orchestrator Setup. This feature page focuses on how templates work for customers (and related admin behaviour) after setup.

For **ISO** images, see the dedicated [ISO](/orchestrator-features/cloudstack/iso) feature page.
