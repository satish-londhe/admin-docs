# VM Backup — CMP workflows

Customer and admin workflows for **VM Backup** on CloudStack in CMP — create, schedule, retain, and restore, with billing via the **VM Backup** package (`BACKUP`).

:::important[Orchestrator-integrated backup]

When CloudStack backup is configured (Automated VM Snapshot as Backup or B&R-Based Backup), customers manage backup from the **VM in CMP**. No agents and no separate backup dashboard.

This is **not** [Veeam VSPC](/orchestrators/veeam/). See **[Backup and Recovery](/overview/backup-and-recovery)** and **[Backup](/orchestrator-features/cloudstack/backup/)**.

:::
