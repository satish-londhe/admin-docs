# VPC Network

A **VPC** (Virtual Private Cloud) in CloudStack provides an isolated private network with one or more guest **tiers**, a **VPC virtual router**, Source NAT, ACLs, optional VPN, and related services.

Customers select a VPC tier package in CMP that maps to CloudStack **VPC Offering** and **VPC Network Offering** values.
