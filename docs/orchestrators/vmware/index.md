# VMware vSphere

This section covers integrating CMP with VMware vSphere as a compute orchestrator.

:::warning[Supported version]

StackConsole supports **VMware vSphere 8 and above**. See [VMware vSphere Requirements](/installation/orchestrator-requirements/vmware) for credentials, API permissions, folder structure, and VM console ports.

:::
