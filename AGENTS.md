# AGENTS.md — CMP Admin Documentation

Cursor agents and humans continuing this repo: **start here.**

2. Read **[`.cursor/UI-AND-DOCS-GUIDE.md`](.cursor/UI-AND-DOCS-GUIDE.md)** — how CMP UI elements map to markdown, page templates, screenshots, and where to add related links.
3. Follow **[`.cursor/rules/doc-sources.mdc`](.cursor/rules/doc-sources.mdc)** (always applied) for Google Doc / Read.ai sources and form-field style.
4. Register and prefer sources in **[`.cursor/sources.json`](.cursor/sources.json)**.
5. MCP setup: **[`.cursor/MCP-SETUP.md`](.cursor/MCP-SETUP.md)**.

**Do not invent product behaviour.** Prefer Google Docs, Read.ai, and author screenshots. Update **both** `sidebars.ts` and `sidebars.js` when adding pages. Put screenshots in `static/img/screenshots/`.
